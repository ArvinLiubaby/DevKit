DevKit 桌面图标设计方案

三个候选概念 · 均已导出 16–1024px 全尺寸 PNG 与 Windows ICO（含 24px）· 基于「本地优先的开发者工具集」定位设计，圆角方形适配 Windows 11 / macOS 风格

方案 A · 命令行提示符

推荐

靛蓝→青色渐变上的白色「>_」终端提示符与光标块，直接呼应全局快捷键唤起的命令面板（Alt+Space），一眼即知是开发者工具。16px 下依然清晰。

实际尺寸 32 / 16 px
浅色任务栏
concept-a-prompt/ · icon.ico / icon-1024.png

方案 B · 花括号

备选

紫罗兰→品红渐变上的白色「{ }」花括号，经典代码符号，强调「为开发者而生」的身份认同，色彩在现代应用图标中辨识度高。

实际尺寸 32 / 16 px
浅色任务栏
concept-b-braces/ · icon.ico / icon-1024.png

方案 C · 工具格

备选

深板岩底色上的 2×2 彩色圆角块，隐喻「工具集」的模块化架构（每个工具即插即用），风格克制，与深色主题 UI 呼应。

实际尺寸 32 / 16 px
浅色任务栏
concept-c-grid/ · icon.ico / icon-1024.png

选定后如何应用到 Tauri 项目

方案 A：npx tauri icon icons/concept-a-prompt/icon-1024.png
方案 B：npx tauri icon icons/concept-b-braces/icon-1024.png
方案 C：npx tauri icon icons/concept-c-grid/icon-1024.png
该命令会自动生成 src-tauri/icons/ 下全平台图标（含 Store 图片与 icns）。
